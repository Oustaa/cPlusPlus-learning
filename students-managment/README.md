The School Management System application includes the following features:

    Student Management
        Add a new student to the system.
        Update an existing student's details.
        Delete a student record.
        View the list of all students.

    Teacher Management
        Add a new teacher to the system.
        Update an existing teacher's details.
        Delete a teacher record.
        View the list of all teachers.

    Class Management
        Create and manage classes.
        Assign students to specific classes.
        Assign teachers to specific subjects within a class.

    Subject Management
        Add, update, and delete subjects.
        View the list of all subjects.
        Assign teachers to specific subjects.

    Performance Tracking
        Record students' grades for each subject.
        View the performance of students in individual subjects.

    Data Persistence
        Store and retrieve all data (students, teachers, classes, subjects, and grades) using files for persistence.

    Search Functionality (Optional)
        Search for students, teachers, or subjects by their ID or name.

    Report Generation (Optional)
        Generate a class performance report, including the average grade and top performers.

    Authentication System (Optional)
        Include login functionality for admins or teachers to access restricted features.

    User Interface
        Provide a menu-driven console interface for navigating the application.
        Ensure the interface is clear and user-friendly.
